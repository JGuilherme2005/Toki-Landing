How does blocking work?

Toki enforces boundaries directly on Windows using local loopback host entries for websites and process management for applications. Toki may request Windows administrator permission because blocking is applied at the system level.

What is Toki?

Toki is a calm Windows desktop focus workspace that combines your timer, tasks, distraction blocking, focus audio, and calendar integrations into one quiet application.

Is Toki just a Pomodoro timer?

No. Toki brings together a focus timer, task context, distraction controls, ambient audio, and task imports so you can enter work without switching apps.

Does it work offline?

Yes. The core timer, distraction blocker, local task list, and built-in ambient soundscapes work offline. Internet connection is required for cloud task imports or streaming audio.

Do I need an account?

No account is required to download Toki or use its core features. Integration credentials for Google Calendar, Notion, and Todoist are stored locally using Windows secure storage.

Which operating systems are supported?

Toki is currently built for Windows 64-bit desktop systems.

Why does Windows ask for administrator permission?

Toki requests Windows UAC administrator elevation on launch because modifying hosts-file DNS rules requires system-level permissions on Windows.

Is the beta free?

Yes. The current Windows beta is 100% free to download and use with no account creation.
