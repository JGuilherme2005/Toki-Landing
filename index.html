A few good things to know.

Is Sylviae free?

The current Windows beta is free to download and use. No account is required for the core tools.

Does it work offline?

The core timer, local tasks, history, blocker preferences, and offline tracks stay on your device. Cloud imports and streaming audio need internet.

Which devices are supported?

The public installer supports Windows 64-bit. The Android companion is a private beta by request; there is no public mobile download or store listing.

Does Android block sites and apps?

Not yet. The Android beta saves your blocklist only. Site and app blocking is a Windows desktop feature.
