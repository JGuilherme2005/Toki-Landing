What is Toki?

Toki is a calm, local-first desktop focus workspace for Windows that unifies your timer, active tasks, focus music, site blocker, and calendar tools into one protected window.

Is Toki just a Pomodoro timer?

No. While it includes a zero-drift Pomodoro engine, Toki is a complete focus environment that defends your work boundaries with desktop blocking, ambient music, and cloud task sync.

Does it work offline?

Yes. The core timer, local distraction blocker, daily workspace tasks, and 5 built-in ambient soundscapes run 100% offline. Internet access is only needed for cloud task sync or streaming Spotify/YouTube audio.

Do I need an account?

No. You download, open, and start a focus block immediately. Credentials and integration tokens are encrypted locally using Windows DPAPI safeStorage.

Which platforms are supported?

Toki is built exclusively as a native desktop application for Windows 64-bit.

How does the distraction blocker work?

Toki terminates chosen application processes (via taskkill), applies local hosts DNS loopback rules, and closes distraction browser tabs during active focus sessions without extensions.

Does Toki connect with Google Calendar, Notion, and Todoist?

Yes. Toki supports 1-click event import from Google Calendar and Todoist, as well as 2-way sync with Notion that updates page statuses and completion timestamps automatically.

Can I use Spotify and YouTube for focus audio?

Yes. In addition to 5 offline CC BY ambient tracks, Toki includes an embedded player dock for Spotify playlists and YouTube audio sources synced with your timer.

Why does Windows ask for administrator permission?

Toki requests Windows UAC administrator elevation on launch because modifying hosts-file DNS rules requires system-level permissions on Windows.

Is the beta free?

Yes. The current Windows beta is 100% free to download and use with no account creation.
